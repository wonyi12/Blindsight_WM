# Relative Blindsight Induced by Incongruency with Working Memory
This repository contains the code and data for the manuscript "Relative Blindsight Induced by Incongruency with Working Memory". All code was written in Python. Below, I describe all the folders and files in detail.

## codes
- The codes folder contains all the code used to run the analyses and generate the outputs and figures. 
- experiment_1_analysis.ipynb — analyses for Experiment 1
- experiment_2_analysis.ipynb — analyses for Experiment 2
- preliminary_experiment_analysis.ipynb — analyses for the preliminary experiment
- supplementary_figures_and_statistics.ipynb — cross-experiment and supplementary analyses

## data 
- This folder contains the individual data of all the participants.

## results
- Contains outputs generated by the analysis notebooks, including:
participant-level summary measures
group-level summary measures
statistical analysis outputs
source data for figures
generated figures
Group-level statistical outputs include descriptive statistics, repeated-measures ANOVAs, pairwise comparisons, signal detection measures, and sphericity checks.
